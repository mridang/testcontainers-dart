  1. @override
Future<(Uint8List, Uint8List)> getLogs()

Returns the service's log output as (stdout, stderr).

Delegates to DockerCompose.getLogs for the service name.

Throws StateError when the parent DockerCompose reference or service name is not set.

Implementation

@override
Future<(Uint8List, Uint8List)> getLogs() async {
  if (_dockerCompose == null) {
    throw StateError('DockerCompose reference not set on ComposeContainer');
  }
  if (service == null) {
    throw StateError('Service name not set on ComposeContainer');
  }
  final (stdout, stderr) = _dockerCompose!.getLogs([service!]);
  return (
    Uint8List.fromList(utf8.encode(stdout)),
    Uint8List.fromList(utf8.encode(stderr)),
  );
}
