Finds and returns the single PublishedPortModel matching the given filters.

Parameters:

  • byPort — filter by PublishedPortModel.targetPort.
  • byHost — filter by PublishedPortModel.url.
  • preferIpVersion — filter by IP version. Default: IpVersion.ipv4.

Throws NoSuchPortExposed when no matching publisher is found or when more than one publisher matches (ambiguous result).

Implementation

PublishedPortModel getPublisher({
  int? byPort,
  String? byHost,
  IpVersion preferIpVersion = IpVersion.ipv4,
}) {
  var remaining = publishers
      .where((r) => _matchesProtocol(preferIpVersion, r))
      .toList();

  if (byPort != null) {
    remaining = remaining.where((r) => r.targetPort == byPort).toList();
  }
  if (byHost != null) {
    remaining = remaining.where((r) => r.url == byHost).toList();
  }

  if (remaining.isEmpty) {
    throw NoSuchPortExposed(
      'Could not find publisher for service $service',
    );
  }

  return _getOnlyElementOrRaise(
    remaining,
    () => NoSuchPortExposed(
      'get_publisher failed because there is not exactly 1 publisher '
      'for service $service when filtering by_port=$byPort, by_host=$byHost '
      '(but ${remaining.length})',
    ),
  );
}
