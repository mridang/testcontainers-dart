DockerCompose

DockerCompose class

Manages a Docker Compose stack in tests.

Wraps the docker compose CLI to bring up a multi-service stack, wait for services to be healthy, introspect containers, and tear the stack down.

All Compose CLI commands are run synchronously via Process.runSync; failures throw ProcessException.

Example:

await DockerCompose.use(
  DockerCompose(
    context: 'test/fixtures',
    composeFileName: 'docker-compose.yaml',
    pull: true,
  ),
  (compose) async {
    final port = compose
      .getContainer('nginx')
      .getPublisher(byPort: 80)
      .publishedPort!;
    final resp = await http.get(Uri.parse('http://localhost:$port/'));
    expect(resp.statusCode, 200);
  },
);
