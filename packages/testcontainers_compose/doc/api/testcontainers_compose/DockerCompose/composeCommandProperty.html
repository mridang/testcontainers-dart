composeCommandProperty property

List<String> composeCommandProperty
latefinal

The base command prefix shared by all Compose CLI invocations.

Lazily built and cached. Includes:

  • [dockerCommandPath, 'compose'] or ['docker', 'compose']
  • -f <file> for each composeFileName
  • --profile <p> for each profiles entry
  • --env-file <e> for each envFile entry

Implementation

late final List<String> composeCommandProperty = List.unmodifiable(() {
  final cmd = dockerCommandPath != null
      ? [dockerCommandPath!, 'compose']
      : ['docker', 'compose'];
  if (composeFileName != null) {
    for (final f in composeFileName!) {
      cmd.addAll(['-f', f]);
    }
  }
  if (profiles != null) {
    for (final p in profiles!) {
      cmd.addAll(['--profile', p]);
    }
  }
  if (envFile != null) {
    for (final e in envFile!) {
      cmd.addAll(['--env-file', e]);
    }
  }
  return cmd;
}());
