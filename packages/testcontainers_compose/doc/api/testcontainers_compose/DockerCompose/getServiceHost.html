Returns the host IP address for a service's published port.

Parameters:

  • serviceName — optional service name.
  • port — optional container port to filter by.

Implementation

String? getServiceHost({String? serviceName, int? port}) {
  final container = getContainer(serviceName);
  final publisher = container.getPublisher(byPort: port).normalize();
  return publisher.url;
}
