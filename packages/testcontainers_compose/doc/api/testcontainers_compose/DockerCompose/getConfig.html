Returns the resolved Compose configuration as a JSON map.

Runs docker compose config --format json with optional normalisation flags. This method is experimental — the output format may change between Docker Compose versions.

A deprecation warning is printed to stderr on the first call.

Parameters:

  • pathResolution — pass --no-path-resolution when false.
  • normalize — pass --no-normalize when false.
  • interpolate — pass --no-interpolate when false.

Implementation

Map<String, dynamic> getConfig({
  bool pathResolution = true,
  bool normalize = true,
  bool interpolate = true,
}) {
  if (_getConfigWarning != null) {
    stderr.writeln(_getConfigWarning);
    _getConfigWarning = null;
  }
  final cmd = [...composeCommandProperty, 'config', '--format', 'json'];
  if (!pathResolution) cmd.add('--no-path-resolution');
  if (!normalize) cmd.add('--no-normalize');
  if (!interpolate) cmd.add('--no-interpolate');
  final result = _runCommand(cmd);
  return jsonDecode(result.stdout as String) as Map<String, dynamic>;
}
