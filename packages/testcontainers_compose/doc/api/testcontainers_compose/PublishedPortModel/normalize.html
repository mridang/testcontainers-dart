PublishedPortModel normalize()

Returns a copy of this model with url normalised for the current Docker host.

Normalisation rules:

  • SSH Docker host (DOCKER_HOST=ssh://…): loopback addresses (0.0.0.0, 127.0.0.1, localhost, ::, ::1) are replaced with the SSH host's hostname so that ports are reachable from the local machine.
  • Windows: 0.0.0.0 is replaced with 127.0.0.1.
  • Other cases: no change; the original model is returned unchanged.

Implementation

PublishedPortModel normalize() {
  var normalizedUrl = url;
  final sshHost = getDockerHostHostname();
  if (sshHost != null &&
      (url == '0.0.0.0' ||
          url == '127.0.0.1' ||
          url == 'localhost' ||
          url == '::' ||
          url == '::1')) {
    normalizedUrl = sshHost;
  } else if (Platform.isWindows && url == '0.0.0.0') {
    normalizedUrl = '127.0.0.1';
  }

  if (normalizedUrl == url) return this;
  return PublishedPortModel(
    url: normalizedUrl,
    targetPort: targetPort,
    publishedPort: publishedPort,
    protocol: protocol,
  );
}
