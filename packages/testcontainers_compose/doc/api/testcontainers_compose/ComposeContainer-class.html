ComposeContainer

ComposeContainer class

Represents a single running service container within a Docker Compose stack.

Instances are returned by DockerCompose.getContainers and DockerCompose.getContainer. They implement WaitStrategyTarget so that standard wait strategies (LogMessageWaitStrategy, HttpWaitStrategy, etc.) can be used directly with Compose services.

Example:

final container = compose.getContainer('db');
await LogMessageWaitStrategy(RegExp(r'ready for connections'))
  .waitUntilReady(container);
