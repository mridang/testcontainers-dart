ryukDisabled property

bool get ryukDisabled

Whether the Ryuk resource-reaper is disabled.

When true, no Ryuk container is started and Docker resources created during a test run will not be cleaned up automatically.

Controlled by TESTCONTAINERS_RYUK_DISABLED or the ryuk.disabled property. Default: false.

Lazily evaluated on first access and cached thereafter.

Implementation

bool get ryukDisabled {
  _ryukDisabled ??= _renderBool('TESTCONTAINERS_RYUK_DISABLED', 'ryuk.disabled');
  return _ryukDisabled!;
}
set ryukDisabled (bool value)

Allows overriding ryukDisabled programmatically (e.g. in tests).

Implementation

set ryukDisabled(bool value) {
  _ryukDisabled = value;
}
