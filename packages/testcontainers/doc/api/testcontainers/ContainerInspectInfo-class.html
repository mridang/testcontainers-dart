ContainerInspectInfo

ContainerInspectInfo class

The complete inspect response for a single Docker container.

This is the top-level model returned by DockerClient.getContainerInspectInfo and ComposeContainer.getContainerInfo. All fields are optional — Docker's response may omit fields depending on the daemon version and the container's state.
