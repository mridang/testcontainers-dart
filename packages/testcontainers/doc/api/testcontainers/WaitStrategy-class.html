WaitStrategy

WaitStrategy class abstract

Abstract base class for all wait strategies.

Provides:

  • Fluent builder methods (withStartupTimeout, withPollInterval, withTransientExceptions) that return this for chaining.
  • An adaptive poll loop that calls a supplied check function at most once per pollInterval second, retrying until the deadline or until the check returns true.

Concrete subclasses must implement waitUntilReady.

Example:

final strategy = PortWaitStrategy(8080)
  ..withStartupTimeout(const Duration(seconds: 30))
  ..withPollInterval(const Duration(milliseconds: 500));
await strategy.waitUntilReady(container);
