Runs command inside the running container and returns its result.

command may be a String (shell-split on spaces/quotes) or a List<String> (used as-is).

Returns (exitCode, combinedOutputBytes).

Throws ContainerStartException when called before start.

Implementation

Future<(int, Uint8List)> exec(dynamic command) async {
  if (_containerId == null) {
    throw const ContainerStartException(
      'Container must be started before executing a command',
    );
  }
  final List<String> cmd;
  if (command is List<String>) {
    cmd = command;
  } else if (command is String) {
    cmd = _splitCommand(command);
  } else {
    throw ArgumentError('command must be a String or List<String>');
  }
  return _dockerClient.execInContainer(_containerId!, cmd);
}
